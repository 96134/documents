一个连乘的式子取余等价于每个乘数取余相乘然后再取余。也就是$(a \times b)\pmod{p}=((a \pmod{p})\times(b \pmod{p}))\pmod{p}$
*<font color="orange">因为可能每个乘数取余相乘后会出现大于取余数的情况。。。</font>

这里给出一个对于没有使用[[快速幂算法]]快速幂算法对于乘方取余的问题：$a ^ n\pmod{p}$
以下是朴素算法的伪代码：
```
function MODNAVIE(a,n,p)
	r = 1
	for i = 1 to n
		r = (r * a) mod p
	return r
```
