数学上某进制转换成十进制可以从低位到高位，每一位按顺序写下并乘以权重，从低位到高位的权重就是某的从零到最高位次减一次幂，也就是：
假设某数的k进制是s，十进制是S，k进制数从低到高位为$a_0 a_1 \dots a_n$
其十进制数为：$a_0 \times k^0+a_1 \times k^1+\dots +a_n \times k^n$


# 关于二进制
计算机的底层对于二进制数进行移位和异或等简单的逻辑运算速度**逻辑运算符的运算顺序优先于移位运算符**很快，
比如想要判断一个数是否为偶数可以写为：
```cpp
!(a & 1) //是偶数的话这个数为真，否则为奇数。
```
***
想要判断一个数的二进制数最后一位是否为一：
```cpp
a % 2 == 1 //是的话为真，否则就不是。
```
用上按位与运算（实际就是判断两个值是否都为真）的话就是：
```cpp
a & 1 == 1 //表示最后一位与1进行位与运算，其他位被置为零了。
```
***
对于一个数除以二向下取整：
```cpp
a = a / 2 //cpp中的除法本身就是向下取整的。
```
用上移位运算的话就是：
```cpp
a >>= 1 //右移一位再给自己赋值就好了。
```

#### 关于十进制转换成其他进制
我们可以根据[[快速幂算法]]的一部分很快的写出一个十进制数的的二进制数，但是如何将十进制数转化成任意（a）进制数，可以将十进制数进入一个循环，这个循环每循环一次都要首先记录这个数对于a取模的数，这位数记为最高位的数字，然后更新这个数按照除以a然后赋值给自己，这个循环停止的条件是a被更新到0为止，伪代码如下：
```
function BASECONVERTION(x,a)
	result = ''
	while x != 0:
		result += to_string(x % a) //这个函数也是cpp
		中的将其他类型强转为string类型的函数
		x /= a
	return result
```
