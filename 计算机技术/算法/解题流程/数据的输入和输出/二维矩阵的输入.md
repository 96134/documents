## 使用动态数组

```cpp
//创建一个大小为NxM的二维矩阵，并初始化所有元素为0
vector<vector<int>> G(N,vector<int>(M));
//输入元素到矩阵中
for(int i=0;i<N;i++){
	for(int j=0;j<M;j++){
		cin>>G[i][j];
	}
}
```

## 使用动态数组和固定数组初始化矩阵

```cpp
vector<vector<int>> G;
for(int i=0;i<N;i++){
	int* a = new int[M];
	//将固定数组a中初始化的元素初始化到动态数组arr中
	vector<int> arr(a,a+M);
	G.push_back(arr); 
}
```
