快速幂算法旨在加快计算乘方的速度，其原理就是将乘方的幂次拆解成由二的幂次相加的多项式然后进行对于每个乘方数计算后相加的方式加快运算的速度。
<font color="orange">这里有个假设就是每一行代码的运行是时间相等的</font>
$a^n=a^{2^0+2^1+\dots+2^k} (2^0+2^1+\dots+2^k = n )( n,k\in \mathbb{Z_+} \bigcup 0)$
# 乘方取模问题
```
function MODFAST(a,n,p)
	a = a mod p
	r = 1
	while n != 0 //这里表示将乘方运算进行完
		if n & 1 == 1: //这里将n进行了拆解，实际上就是将作为二进制数的n中的1每一个都单独拎了出来，参照二进制转换成十进制，依照下面的表格。
			r = r x a mod p
		a = a x a mod p
		n >>= 1
	return r
```
上面伪代码中的按位与运算和移位运算可参照[[进制]]
